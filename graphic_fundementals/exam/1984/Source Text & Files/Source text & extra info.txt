Some extra tips:
On the Spine of the Book (the left side part), the text written vertically "GEORGE ORWELL", "1984" and the 2 lines use the 'Style 1984' from the GRAFUN 1984 Library provided with the source files. 
Importing and using this preset will save you time of figuring out which layer style was used. If you don't know how to import it, you still need to remake the layer style yourself.
